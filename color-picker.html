What are HEX and RGB?

HEX is a six-digit code that describes a color, such as #FF0000 for red. RGB describes the same color as three numbers for red, green and blue, such as rgb(255, 0, 0). Both are used in websites, apps and design software.

FAQs

What is a HEX code?
A six-digit code for a color, for example #FF0000 is red and #0000FF is blue.

What is RGB?
RGB is the same color written as three numbers for red, green, and blue — for example rgb(255, 0, 0) is red.
